# Lagoa Viva

Jogo educativo de ecologia aquática: acompanhe o lambari na lagoa, explore as zonas de superfície e fundo, encontre alimento e abrigo e observe os efeitos de predadores e da qualidade da água.

## Jogar

A página principal é `index.html`. O jogo usa os arquivos de `game-assets/`.

## Publicação

Para publicar, abra **Settings → Pages** no repositório, selecione **Deploy from a branch**, escolha `main` e a pasta `/(root)`. Depois de salvar, o GitHub Pages disponibiliza o jogo em `https://ernandes-sobreira.github.io/lagoa-viva/`.

## Ranking

Os resultados são guardados no navegador deste dispositivo. Para manter privacidade e dispensar cadastro, o ranking ainda não é compartilhado entre dispositivos.

Versão do jogo originalmente mantida em [jogos-ambientais](https://github.com/ernandes-sobreira/jogos-ambientais).
